# Fresh section chats, Nov 5 2026

The desktop app reads a chat's whole transcript on its main thread when the chat opens. By Nov 5 the permanent
section chats' transcripts were 58 to 98 MB each, so opening any one froze every chat for tens of seconds and
the app looked crashed. The fix is a fresh session per section, started from the real checkout, with the old
chat archived (never deleted: its transcript stays on disk under `~/.claude/projects/`).

**Rule from now on (Caleb, Nov 5):** when a section chat's transcript passes about 40 MB
(`ls -la ~/.claude/projects/*/<session id>.jsonl`), the Master Agent writes it a handoff here, Caleb starts a fresh
session with the same title, model and effort, pastes the handoff, and archives the old one. Nothing a chat needs
lives only in its transcript: the repo, `docs/agents/STATE.md`, the tracker and `docs/agents/memory/` hold it.

## How to start each one (Caleb, about a minute a chat)

1. Sidebar → **New**. Folder: `/Users/calebwang/GitHub/homecookd/homecookd` (the real path; the label becomes "homecookd").
2. Rename it to the title below. Model and effort: Master Agent on Fable 5.1 effort high; the others as they were
   (Opus, medium).
3. Paste that chat's handoff as the first message.
4. Right-click the old chat → **Archive**.

Do the Master Agent first, so the others have someone to report to.
