# Kid feedback: preserve Hearth while decluttering

Date: Oct 21, 2026

Caleb reviewed four kid-profile sessions (Caden, Neil, Elliot, Joanna) and authorized two parallel workstreams: implement essential playback/profile fixes, and produce cooking-journey mockups for review. The journey redesign is not approved for production implementation yet.

**Why:** media and family voices attracted engagement, but text density, unclear entry points, and step navigation distracted from cooking. The current visual design is good; this is simplification, not a rebrand.

**How to apply:** preserve the current Hearth palette, Fraunces/DM Sans typography, pot illustrations, surfaces, and design principles. Use current app code and the design bible as references. Mock up Home, a full recipe overview, clearer cooking steps, and optional stories before building those changes. Do not treat each individual suggestion as a validated requirement. Distinguish absent sample recordings from broken playback, and reproduce profile taps before claiming a fix.

Evidence: text overload and step-navigation confusion were explicit for three of four participants; homepage paralysis and distracting quotes for two. All four engaged with media and encountered different playback limitations. Only Caden explicitly requested the entire recipe before starting; Elliot liked the quotes.
